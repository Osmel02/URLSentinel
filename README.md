# URLSentinel
Extensión de navegador enfocada en ciberseguridad que analiza en tiempo real las URLs visitadas por el usuario para detectar amenazas, como phishing, dominios maliciosos y enlaces sospechosos. El proyecto aplica técnicas de análisis automatizado para evaluar el riesgo de cada URL y alertar al usuario antes de que interactúe con contenido potencialmente peligroso.
